# OSN+ Public Catalog Tracker

لوحة محلية لمراقبة صفحات كتالوج OSN+ العامة وروابط الصور التي تظهر فيها.

## التشغيل على Windows
1. ثبّت Python 3.11 أو أحدث من https://www.python.org/downloads/ (فعّل خيار Add Python to PATH).
2. فك ضغط الملف.
3. افتح CMD داخل المجلد وشغّل:
   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. ستفتح اللوحة في المتصفح غالبًا على `http://localhost:8501`.

## ما الذي تفعله؟
- تفحص صفحات الكتالوج العامة المحددة داخل `app.py`.
- تحفظ عناوين الأعمال وروابط صفحاتها والصور المرتبطة بها في SQLite.
- تسجل أول وآخر وقت رصدت فيه كل سجل.
- تعرض السجلات وتسمح بتصدير CSV.
- تعيد الفحص تلقائيًا أثناء بقاء التطبيق مفتوحًا.

## حدود مهمة
- هذه نسخة أولية تعتمد على HTML العام، وليست ماسحًا شاملًا لكل ملفات CDN أو لكل ما هو مخفي خلف API.
- "أول اكتشاف" يعني أول مرة بدأ البرنامج برصد السجل، وليس تاريخ رفعه الحقيقي.
- قد تتغير صفحات OSN+ أو تُحمّل ديناميكيًا؛ إذا ظهرت نتائج قليلة، يلزم تحديث طريقة الاستخراج بعد فحص بنية الصفحة/واجهات API العامة المسموح بها.
- لا تستخرج ملفات الفيديو ولا تتجاوز DRM أو تسجيل الدخول أو قيود الوصول. تعرض فقط بيانات وروابط ظاهرة علنًا.
- الفحص يعمل ما دام جهازك والتطبيق يعملان. لتشغيل مستمر 24/7، شغّله على جهاز دائم التشغيل أو خادم تملكه وتتحكم به.
